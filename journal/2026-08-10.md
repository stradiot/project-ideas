## homepage

Implemented typed IP address lookup: bare IPv4 addresses and bracketed IPv6 addresses (with optional port and path) now navigate directly instead of triggering a Google search. Added octect range validation to reject malformed addresses like `1.2.3.400`, and automatic scheme selection (http for private/loopback ranges, https otherwise) so LAN devices like Home Assistant don't get broken by HTTPS defaults.

The implementation treats bare dotted-quads (`1.2.3.4`) as IP addresses rather than version numbers or search terms. This means typing `v1.2.3.4 release notes` still searches (whitespace disqualifies it early), but a lone `1.2.3.4` navigates. Tested against 15 cases — behavior matched expectations across IPv4 bare/port/path combos and IPv6 brackets. Committed directly to main as f3a2c5a.

Minor behavior change: `localhost` now resolves to `http://` instead of `https://`, matching the private-range heuristic. This is correct for a homepage tool but is a change beyond the literal ask. If the bare-IP-as-address assumption turns out to be wrong later (e.g., if version numbers feel more natural), it's a line change away.
